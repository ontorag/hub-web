# .impeccable

## Design Context

### Users
Technical, ontology-minded builders (data/knowledge engineers, RAG/AI devs) turning a
document corpus into a **governed knowledge graph**. They bring their own GitHub + LLM
key, work in focused sessions, and care about structure, provenance, and control
("LLMs propose, code decides, humans govern"). The product is literally about *concepts
and their connections* — so the interface should feel like an instrument for drawing structure.

### Brand Personality
Precise · structural · drafted. An engineering instrument, not a SaaS app. Confident,
exacting, a little severe. Evokes: a drafting table, a spec sheet, a CAD viewport, an
oscilloscope. Should make someone ask "how was this built?", never "which AI made this?"

### Aesthetic Direction
**Blueprint / schematic.** A faint coordinate grid substrate; hairline (1px) rules
instead of shadowed cards; sheets with accent **registration ticks** at the corners;
mono **section coordinates** (§ A.2, ticks); the ontology graph styled as a technical
diagram and treated as the hero. Restrained motion (hairlines draw in on load).
- **Theme:** light **and** dark via `light-dark()` + `color-scheme: light dark` (follow OS).
- **Palette:** graphite neutrals tinted cool (hue ~250), one **electric-lime** signal accent
  (oklch ~0.80–0.86 / 0.19 / 128) used at ~10% — markers, current step, primary action.
- **Anti-references:** NOT crypto dark-neon (no glowing cyan/purple, no gradient text/fills);
  NOT stiff enterprise (no corporate-blue, no safe gray cards, no drop-shadow rounded rects).

### Typography
- Display / titles: **Archivo Expanded** (700/800) — engineered, wide, spec-sheet.
- Body / reading: **Hanken Grotesk** — clean grotesque, 65–75ch measure.
- Technical layer: **Martian Mono** — identifiers, IRIs, slugs, labels, coordinates, chips.
- (Reflex fonts — Inter, DM, Space*, IBM Plex*, Fraunces, etc. — explicitly rejected.)

### Design Principles
1. **The line is the material.** Structure with 1px hairlines + corner ticks, never shadows.
2. **Grid is truth.** A coordinate grid underlies everything; content snaps to a 4pt scale.
3. **Mono is meaning.** Monospace only for real technical content (IRIs, slugs, coordinates) — never decoration.
4. **The accent is rare.** Electric lime marks exactly one thing: where you are / the primary act.
5. **The graph is the hero.** The ontology reads as a precise technical drawing.
